# VK WorkSpace — прототип (функции недоступны)

Нерабочий прототип. Создание видеовстреч, календарная синхронизация, VK Teams, почта и диск недоступны. Пакет не подключается к VK WorkSpace и не создаёт внешние встречи, ссылки или фиктивные идентификаторы.

A module for the [TropaTT](https://github.com/Anton-Barinov/TropaTT) self-hosted CRM and work platform.

## Installation

### Method 1: TropaTT Marketplace (Recommended)

1. In your TropaTT CRM, navigate to **Admin → Modules → Marketplace**.
2. Search for **VK WorkSpace — прототип (функции недоступны)** (`crm.vk-workspace`).
3. Click **Install**.

### Method 2: Manual ZIP Upload

1. Download `crm.vk-workspace-1.0.5.zip` from the [Releases](https://github.com/Anton-Barinov/tropatt-module-vk-workspace/releases) tab.
2. In TropaTT CRM, navigate to **Admin → Modules**.
3. Click **Upload Module** and select the downloaded ZIP file.
4. Activate and configure the module in **Admin → Modules**.
